## 🏛️ What We Do

Linkest Foundation provides the legal, technical, and infrastructural scaffolding that allows independent developers to focus on creating. We believe that creators should own their data, their code, and their future.

### 🛡️ Security & CNA Governance
We operate a rigorous vulnerability disclosure ecosystem. Our team actively participates in the **CVE Program** (via the MITRE Automation Working Group and OCWG).
*   **Strict Disclosure**: We enforce a strict 90-day responsible disclosure timeline.
*   **CVE Assignment**: We coordinate vulnerability handling and CVE ID assignment through centralized GHSA processes.
*   **Hardware-Backed Security**: We enforce FIDO2/Passkeys for critical infrastructure access.

### 🚀 Project Incubation & Hosting
We provide a safe harbor for independent projects:
*   **GitHub Organization Hosting**: A centralized, audited space for code collaboration.
*   **Edge Infrastructure**: Zero-cost, highly available serverless deployment via Cloudflare Workers, Pages, and D1.
*   **Uptime Monitoring**: Mandatory onboarding to our [public status page](https://status.linkest.org) for transparency.

### 📜 Legal & Compliance
We protect creators' rights through strict open-source compliance:
*   **Dual Licensing**: Code is typically licensed under **GPL-3.0** or **AGPL-3.0**. Creative assets are licensed under **CC BY-NC-SA 4.0**.
*   **Contributor License Agreement (CLA)**: All contributors must sign our CLA to ensure the foundation can legally protect the ecosystem.

## 📥 Join the Ecosystem

We welcome independent developers, designers, and security researchers. You must meet these core requirements:

1.  **A Project or Roadmap**: Have an active open-source project or a detailed development plan.
2.  **GitHub Presence**: An active GitHub account with a public repository demonstrating real code history.
3.  **Transparency**: Public-facing projects must be onboarded to **Linkest Foundation Status Monitoring**.
4.  **Security First**: Agree to our [Security Policy](https://linkest.org/security.html) and follow responsible disclosure principles.
5.  **AI Accountability**: AI tools are welcome, but human oversight is mandatory. You are solely responsible for any vulnerabilities introduced by AI-generated code.

*Read the full [Joining Guide & Code of Conduct](https://linkest.org/join.html) before applying.*
